🔍 Detection Schwellwerte

ALERT_ENTROPY_ABS = 7.8 bits/byte
Typische Werte:
  • <5.0 – Text, Quellcode (niedrig)
  • 5.0-7.0 – Komprimierte Dateien (mittel)
  • ≥7.8 – Verschlüsselt/Random = ⚠️ ALARM

📊 Defense-Ebenen im Detail

Ebene Technologie Was wird erkannt Aktion
1️⃣ Entropy Shannon-Entropie (NumPy/ent) Plötzliches Encryption/Random Flag + DB Write
2️⃣ Malware ClamAV Signaturen Bekannte Viren/Trojaner Quarantäne + Alert
3️⃣ Temporal HEALTH_SAFEAGE_MIN Zu frische/verdächtige Änderungen YELLOW Status
4️⃣ Fingerprint Quick-FP (Head+Tail MD5) Mtime-Manipulation → neuer Inhalt Volle Re-Verifizierung
5️⃣ Gate safety_gate.sh Exit-Code Aggregierter Status aller Checks ❌ Backup BLOCKIERT
✅ Resultat: Aktive Ransomware-Bedrohung wird erkannt BEVOR Backup läuft → verschlüsselte Dateien landen NICHT in pCloud!
